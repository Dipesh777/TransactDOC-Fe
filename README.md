# 📄 Document Parser Frontend

A React application for user authentication, PDF upload, document listing, and preview using protected routes.

---

## 🚀 Features

- User Login & Logout
- JWT-based Authentication
- Public & Private Routes
- PDF Upload UI
- Parsed Data Table
- Document Preview
- Axios API integration

---

## 🛠️ Tech Stack

- React.js
- React Router DOM v6
- Axios
- Context API
- Tailwind / CSS
- JWT Authentication
